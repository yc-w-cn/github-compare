# GitHub 仓库对比工具

简洁高效的 GitHub 仓库对比工具，帮助你快速了解和比较不同仓库的关键指标。

## 功能特性

### 多仓库对比
- 支持同时对比多个 GitHub 仓库
- 一目了然地查看各仓库的核心数据

### 关键指标展示
- **Stars** - 仓库获得的星标数量
- **Forks** - 仓库的复刻数量
- **Issues** - 开放的议题数量
- **语言** - 主要编程语言
- **大小** - 仓库代码大小
- **更新时间** - 最后更新日期

### 界面设计
- 简洁清晰的表格布局
- 支持深色模式
- 响应式设计，适配各种屏幕尺寸
- 数据格式化显示（大数字使用 K/M 单位）

### 表格排序
- 支持按多个指标对仓库列表进行排序
- 可排序字段：Stars、Forks、Issues、更新时间、仓库大小
- 点击表头可切换升序/降序排序
- 排序状态通过箭头图标直观显示

### 数据展示
- 实时显示最后更新时间
- 仓库描述信息
- 点击仓库名称可直接跳转到 GitHub

## 使用方式

访问网站即可查看已配置的 GitHub 仓库对比信息。所有数据通过 GitHub API 获取并实时展示。
